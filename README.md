# Himalayan Otaku — Free Website

## Files
- `index.html` — website structure
- `style.css` — design
- `script.js` — products, cart and WhatsApp checkout

## Before publishing
1. Replace the sample product names/prices.
2. Replace `977XXXXXXXXXX` in `script.js` with your WhatsApp number.
3. Replace the Instagram and WhatsApp links in `index.html`.
4. Replace the placeholder product boxes with your real T-shirt photos.
5. Publish using GitHub Pages.

This version is intentionally zero-cost and uses WhatsApp for orders instead of paid e-commerce/payment integrations.
